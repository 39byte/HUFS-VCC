# 학점 손익계산서

2026 한국외대 × 네이버클라우드 바이브코딩 경진대회 · 팀 갓생추구

익명으로 성적을 입력하면 **성적 때문에 지원 자격이 없었던 장학금·기회**를 금액과 목록으로 보여 주고,
**목표 평점까지 남은 학기 평균**을 역산하고, 항상 **다음 학기 회복 경로**로 끝나는 웹서비스입니다.

## 약속

- 이름·학번·학과·과목명을 받지 않습니다. 로그인 없음.
- 성적은 브라우저 밖으로 나가지 않습니다. 서버·DB·애널리틱스 없음 (정적 사이트).
- 다른 학생과 비교하지 않습니다.
- "이 기기에 저장"을 켰을 때만 `localStorage`에 저장합니다 (기본 OFF).

## 개발

```bash
npm install
npm run dev     # 로컬 실행
npm test        # 계산 로직 테스트 (vitest)
npm run build   # dist/ 정적 파일 생성
```

## 구조

- `src/lib/` — 평점(절사), 목표 역산, 놓친 기회·회복·하락 시뮬, 문구(순한맛/매운맛)
- `src/data/rules.json` — 학사 상수 (학점 체계, 졸업 학점, 학사경고 등)
- `src/data/opportunities.json` — 기회 기준 DB. 모든 항목에 원문 URL·확인일
- `scripts/structure-notices.ts` — (개발용) HyperCLOVA X로 공지 원문 → JSON 초안. 사람이 원문 대조 후 커밋

## 배포 (네이버클라우드)

`npm run build` 후 `dist/`를 NCP Object Storage 버킷에 업로드하고 정적 웹 호스팅을 켭니다
(`vite.config.ts`의 `base: './'`로 하위 경로에서도 동작). 라우팅은 해시(`#/input`, `#/result`)라 서버 설정이 필요 없습니다.

## 데이터 주의

기준은 2026-11-04 기준 공개 공지에서 확인한 값입니다. 학번·캠퍼스에 따라 다를 수 있으며, 화면의 모든 기회에 원문 링크가 붙어 있습니다.
"놓친 장학금"은 선발을 보장하는 금액이 아닌 추정치입니다.
